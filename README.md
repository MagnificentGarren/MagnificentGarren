## 🚀 Featured Production Projects

### 🔭 Reposeer: AI-Powered Repository Intelligence & Architectural Interview Simulator
An architecture-aware developer platform and interview simulator ([reposeer.vercel.app](https://reposeer.vercel.app/)) designed to turn unfamiliar repositories into structured, navigable systems for deep technical evaluation.
- **AST Parsing & Dependency Mapping:** Built an ingestion engine using **Tree-sitter** and **NetworkX** to parse Python AST structures, extract module import relationships, and render interactive dependency graphs.
- **Durable Queue & Live Telemetry:** Engineered a fault-tolerant inspection pipeline in FastAPI backed by PostgreSQL row locks, renewable job leases, and real-time progress streaming.
- **Repository-Aware AI & Interview Mode:** Integrated Google Gemini with Supabase Auth to power context-aware codebase exploration and generate repository-specific architecture scenarios that evaluate engineering trade-offs under pressure.
- **Modern Dev Workspace:** Built an interactive frontend using Next.js 16, React 19, React Flow, and Tailwind CSS, containerised via Docker Compose.

### 💳 HimLedger: Enterprise Expense Management & Audit Platform
A full-stack corporate expense lifecycle platform built with Clean Architecture to enforce financial accountability, role-based governance, and end-to-end auditability.
- **Layered .NET Architecture:** Structured across distinct `Api`, `Application`, `Domain`, and `Infrastructure` boundaries using **.NET 8**, **ASP.NET Core**, **Entity Framework Core**, and **SQL Server**.
- **RBAC & Operational Audit Trail:** Enforces strict role-based authorisation across Employee, Manager, Finance, and Admin workflows alongside a dedicated audit workspace tracking system-wide state changes.
- **Cloud-Native Azure Infrastructure:** Provisioned with **Bicep** Infrastructure as Code targeting Azure App Service, Azure Key Vault, Application Insights, and Entra ID, backed by xUnit, Vitest, and Playwright test suites.

### 🧠 Metanoia: Gamified Focus & Productivity Android Application
A native, local-first Android productivity and habit-building application engineered to turn long-term goals into consistent daily execution.
- **Reactive MVVM & Local-First Persistence:** Archected using **Kotlin**, **MVVM**, **Kotlin Coroutines & Flow**, and **Room Database (SQLite)** for offline-first project, session, and achievement tracking.
- **Background Lifecycle & Authentication:** Engineered resilient background focus timers using Android Foreground Services and scheduled notifications, paired with **Firebase Authentication** and Google Sign-In via Android Credential Manager.
- **Gamified Progression Engine:** Built a custom `AchievementsEngine` awarding milestone medals and collectible avatars to reinforce daily focus routines.

## 📊 Core Engineering Philosophies

- **Ship the Core, Then Expand:** Every product starts by solving one specific problem cleanly and reliably before layering on secondary workflows, analytics, or automation.
- **Zero-Vulnerability Data Pipelines:** I don't build standard, vulnerable CRUD apps. All data layers are reinforced with strict server-side validation, prepared statements or parameterised ORMs, and role-scoped access control.
- **Resilient State & Lifecycle Management:** Experienced in designing durable execution models—from lease-backed background job queues and human-in-the-loop state checkpoints to Android foreground services that survive lifecycle interruptions.
- **Clean Architecture & Automated Verification:** Passionate about separating domain logic from infrastructure, pairing Infrastructure as Code with automated unit, integration, and end-to-end test suites.
